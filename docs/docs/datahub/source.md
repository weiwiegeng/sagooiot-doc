# 数据源管理

数据中心把多源数据收拢为可复用的数据集，供建模、指标与可视化使用。

当前支持的数据来源：

| 类型 | 说明 |
|------|------|
| **api导入** | 定时拉取第三方 HTTP/HTTPS 接口。详见 [HTTP API 数据源](./source-api.md)（含鉴权配置） |
| **设备** | 绑定产品或设备，节点映射物模型属性（时序入库） |
| **数据库** | 直连 MySQL / MSSQL，表或自定义 SQL，支持增量与定时同步 |

:::tip
HTTP API 的 OAuth2、Bearer、API Key、自定义 Token 等鉴权请直接阅读 [HTTP API 数据源](./source-api.md)。
:::

## 名词解释

### 数据源

设备上报、第三方 API 或业务库拉取到的数据集合，供建模与前端查询。

### 数据节点

类似表字段；多个节点组成一个数据源，查询时读取具体节点。

### 取值项

确定取值路径：JSON 用节点路径；设备用来源产品的物模型属性。

### 规则表达式

按节点过滤数据，仅对本节点生效（如正则替换、清洗规则）。

## 创建数据源

1. 进入 **数据中心 → 数据源**，新建数据源  
2. 选择数据来源（api / 设备 / 数据库）并填写标识、名称  
3. 按来源填写连接或请求配置；API 务必配置鉴权（见专篇）  
4. 配置更新周期（cron），说明见 [定时任务设置](../other/cron.md)，可用 [在线 Cron 生成器](https://cron.qqe2.com/)  
5. 配置数据节点与规则后预览，确认无误再 **发布**

## 数据节点管理

在数据源详情中维护节点：绑定取值路径、数据类型、是否主键、清洗规则等。API 源节点通常对应响应 JSON 路径；设备源对应物模型属性；数据库源对应列或 SQL 别名。

## 注意事项

- 直连数据库自定义 SQL 时控制单次拉取量，避免内存压力过大  
- API 源修改密钥或鉴权方式后保存，会清空该源 Token 缓存并在下次同步重新取票  
- 文件类数据源枚举存在，当前产品界面未开放，请勿当作已交付能力
