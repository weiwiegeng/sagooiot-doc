# 数据建模

把一个或多个**已采集的数据源**拼成业务宽表，按 Cron 同步入库，供指标计算、大屏与业务查询使用。

路径：**数据中心 → 数据建模**。

```text
已发布数据源 → 配置模型与字段 →（多源）设置关联 →（可选）聚合设置 → 发布 → 定时入库 → 数据记录 / 指标
```

---

## 名词说明

| 概念 | 说明 |
|------|------|
| **数据模型** | 宽表定义（模板）。发布后在数据中心库中生成物理表，并挂接定时任务拉取数据。 |
| **字段节点** | 模型上的一列。可来自数据源节点，也可自定义常量/默认值列。 |
| **主源 / 关联字段** | 多数据源拼表时，以主源行为驱动，按关联字段（源字段 key）对齐其它源。 |
| **聚合设置** | 按时间窗口对数值字段做 max/min/avg/sum，并可选分组。 |
| **发布** | 建表、锁定标识、创建并启动 Cron 任务，且立即执行一次同步。 |

物理表名规则：`data_template_{模型ID}`（一般无需手填，发布后由系统创建）。

---

## 前置条件

1. 先在 [数据源管理](./source.md) 建好并**发布**数据源，保证源表已有数据节点  
2. API 源注意鉴权与能预览到 JSON，见 [HTTP API 数据源](./source-api.md)  
3. 模型至少添加 **1 个字段节点** 才能发布  
4. 若字段来自多个数据源，发布前必须完成 [多源关联](#多源关联)

---

## 新增模型

列表页点击 **新增模型**：

| 参数 | 必填 | 说明 |
|------|------|------|
| 模型标识 | 是 | 唯一；字母/数字/下划线，非数字开头。**首次发布后永久锁定**，取消发布也不可改 |
| 模型名称 | 是 | 显示名称 |
| 模型类型 | 是 | 字典分类（`datahub_model_type`） |
| 定时请求 | 是 | Cron，控制同步周期；见 [定时任务设置](../other/cron.md) |
| 描述 | 否 | 最长约 200 字 |
| 单元类型 | 否 | 业务单元多选（`busi_types`） |

保存后状态为 **未发布**。未发布时可改基本信息；**已发布**须先取消发布再改。

### 其它列表操作

| 操作 | 说明 |
|------|------|
| 修改 | 仅未发布 |
| 复制 | 生成新标识（原标识_时间戳），复制全部字段节点，新模型为未发布 |
| 删除 | 仅未发布；软删模型与节点，并删除定时任务与物理表 |
| 字段管理 | 进入节点/关联/聚合/发布页 |
| 数据记录 | 已发布后可分页查看模型表数据 |

## 字段管理

在 **字段管理** 中维护模型列。未发布时可新增 / 编辑 / 删除；已发布后界面锁定结构变更（需先取消发布）。

### 字段来源

| 类型 | 说明 |
|------|------|
| **数据源** | 选择已用数据源及其节点；自动带出字段名称、标题、数据类型 |
| **自定义** | 不绑源节点；可用默认值；空默认值时运行期可按 GUID 填充 |

### 字段配置

| 参数 | 必填 | 说明 |
|------|------|------|
| 字段名称 | 是 | 列标识，模型内唯一；创建后接口侧不可改标识 |
| 字段标题 | 是 | 展示名 |
| 数据类型 | 是 | `int` / `long` / `float` / `double` / `string` / `boolean` / `date` |
| 取值方法 | 否 | 绑数据源的数值字段：`默认` / `最大值` / `最小值` / `平均值` / `求和`。与 [聚合设置](#聚合设置) 配合才生效 |
| 默认值 | 否 | 仅自定义字段 |
| 是否为主键 | 否 | 发布建表时建唯一约束（表自身主键仍为系统 `__id__`） |
| 是否排序 | 否 | 开启后作为「数据记录」默认排序列 |
| 排序方式 | 条件 | 降序 / 升序 |
| 备注说明 | 否 | 备注 |

:::tip 取值方法
仅当配置了有效的时间窗聚合，且字段方法为 max/min/avg/sum 时，数据库源 / 设备源会按窗口聚合取值。API 源按最新记录拉取，**不做**时间窗 SQL 聚合。
:::

## 多源关联

当模型字段映射到 **2 个及以上不同数据源** 时，发布前需设置：

| 参数 | 必填 | 说明 |
|------|------|------|
| 主数据源 | 是 | 驱动对齐的主源 |
| 关联字段（数据源节点） | 是 | 各源上用于对齐的字段 key；其它源按同 key 取值，对不上则为空/0 |

发布时若尚未配置，系统会提示 **设置主源、关联字段**，配置完成后再发布。

- **已配置关联**：按关联键合并行（主源驱动）  
- **单源或未配置关联**：按行号对齐合并（各源行数不一致时结果可能错位，多源场景务必配置关联）

关联仅在未发布时可修改。

## 聚合设置

用于按时间切片汇总数值列。路径：字段管理页 → **聚合设置**（仅未发布可改）。

| 参数 | 必填 | 说明 |
|------|------|------|
| 分组节点 | 界面必填 | 分组字段（源字段 key）；后端允许为空（不分组） |
| 时间窗口节点 | 是 | 时间起点字段（源字段 key） |
| 时间值 | 是 | 窗口长度，≥1 |
| 时间单位 | 是 | 秒 / 分 / 时 / 天 |

生效条件（同时满足）：

1. 已配置时间窗口节点、时长、单位  
2. 至少一个字段取值方法为 max / min / avg / sum  

候选节点来自**主源**（未设主源则取模型用到的第一个源）的源节点列表。

### 各源行为差异

| 数据源类型 | 聚合行为摘要 |
|------------|----------------|
| **数据库** | 按窗口做分组聚合；增量常依赖源表时间相关列。时间节点需与源表时间字段匹配，否则窗口可能取不到数据 |
| **设备** | 按窗口步进聚合；产品维度另有 latest lookback 等配置影响取数范围 |
| **API** | 取最新批次映射，不适用上述时间窗 SQL 聚合 |

未启用聚合时，数据库源多为按主键增量拉取限定条数。

## 发布与取消发布

### 发布检查清单

- [ ] 至少 1 个字段节点  
- [ ] 多源已设置主源 + 关联字段  
- [ ] Cron 已配置  
- [ ] （可选）数值字段取值方法 + 聚合设置  
- [ ] 上游数据源已发布且有数据  

### 发布后系统行为

1. 若尚无物理表则建表（字段含节点列，以及 `__id__`、`created_at`、`updated_at`、`__count__`；含设备源时另有 `deviceKey`）  
2. 状态改为已发布，并锁定模型标识  
3. 创建/更新定时任务并启动，**立即执行一次**同步  

### 取消发布

- 状态改回未发布，**停止**定时任务  
- **不**删除物理表，也不解除标识锁定  
- 可再次调整字段、关联、聚合后重新发布

## 数据记录

模型 **已发布** 后，列表提供 **数据记录**：分页查看当前模型表内容。

- 列标题优先用字段「字段标题」  
- 默认排序：若配置了排序字段则按其规则，否则按 `created_at` 倒序  

用于验收 Cron 与关联/聚合是否生效；改结构请先取消发布。

---

## 推荐操作流程

1. 创建并发布数据源，确认源数据可读  
2. **新增模型**，配置 Cron  
3. **字段管理**：从数据源添加字段；需要常量列时用自定义  
4. 多源则 **设置主源、关联字段**  
5. 需要汇总时配置字段取值方法 + **聚合设置**  
6. **发布**，打开 **数据记录** 核对  
7. 在 [指标管理](./indicator.md) 中绑定本模型 KEY，做定时计算等

---

## 注意事项

- 先取消发布才能改模型结构、关联与聚合；改完再发布  
- 标识一旦发布即锁定，请新建时想好命名  
- 取消发布不会清历史表数据；删除模型（未发布）会删表  
- 多源务必配关联，避免按行号错位合并  
- 定时计算类指标依赖建模持续入库，详见指标文档中的前置说明  

上手数据源请先读 [数据源管理](./source.md)；API 鉴权见 [HTTP API 数据源](./source-api.md)。
