# 插件使用概述

SagooIoT 通过插件扩展设备接入能力。本目录文档来源于服务端 `plugins` 目录下各插件的 README，**重点说明配置参数、物模型点位扩展配置与下行控制相关项**。

:::info 范围说明
当前仅覆盖带 README 的驱动/协议插件。通知类插件（短信、邮件、企微等）请参考「通知服务」手册；平台层安装启用见「配置中心 / 插件管理」。
:::

## 通用步骤

1. **安装插件**：将编译产物（如 `driver-modbus`）与 `info.json` 打成 zip，在「插件管理」中上传安装并启用。
2. **配置产品**：在产品上选择对应「消息协议」或采集驱动。
3. **配置设备连接**：在设备侧（或采集通道）填写连接参数（IP、串口、鉴权等）。
4. **配置物模型点位**：在属性 `extConfig` 中绑定协议点位（寄存器、OID、NodeID、IOA 等）。
5. **启用采集/联调**：结合网络服务、隧道或主动轮询，验证上报与功能下发。
