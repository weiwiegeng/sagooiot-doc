# DL/T 645-2007 驱动插件

经 RS-485 与多功能电能表通信，默认 2400bps、偶校验。

## 插件级配置

| 参数 | 默认值 | 说明 |
|------|--------|------|
| defaultTimeout | 5 | 请求超时（秒） |

## 设备连接配置

| 参数 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| serialPort | 是 | - | 如 `/dev/ttyUSB0`、`COM3` |
| meterAddress | 是 | - | 12 位电表地址 |
| baudRate | 否 | 2400 | 1200/2400/4800/9600/19200 |
| dataBits | 否 | 8 | 7/8 |
| stopBits | 否 | 1 | 1/2 |
| parity | 否 | E | N/E/O |
| rs485Enabled | 否 | false | RS-485 收发控制 |
| timeout | 否 | 5 | 串口超时（秒） |

## 物模型点位配置

| 字段 | 说明 |
|------|------|
| dataMarker | 8 位十六进制数据标识 |
| dataType | BCD 策略：`auto`/`energy`/`voltage`/`current`/`power` |
| blockQuantity | 连续块数 1–10 |
| scale / offset | 数值变换 |
| writable | 是否可写 |

常用标识：`00000000` 组合有功总电能，`02010100` A 相电压，`02020100` A 相电流，`02030000` 瞬时总有功功率。

支持写数据、写地址与冻结命令（需配合密码/操作者代码等写配置）。
