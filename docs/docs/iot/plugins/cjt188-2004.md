# CJ/T 188-2004 驱动插件

经 RS-485 接入水表、热量表、燃气表等户用仪表。

## 插件级配置

| 参数 | 默认值 | 说明 |
|------|--------|------|
| defaultTimeout | 5 | 请求超时（秒） |

## 设备连接配置

| 参数 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| serialPort | 是 | - | 串口地址 |
| meterAddress | 是 | - | 14 位表计地址 |
| meterType | 否 | 10 | 见表计类型 |
| baudRate | 否 | 2400 | 1200/2400/4800/9600 |
| timeout | 否 | 5 | 接收超时（秒） |

### 表计类型

| 值 | 含义 |
|----|------|
| 10–13 | 冷水/生活热水/直饮水/中水水表 |
| 20 / 21 | 热量表（计热量/计冷量） |
| 30 | 燃气表 |

## 物模型点位配置

| 字段 | 说明 |
|------|------|
| dataIdentifier | 4 位十六进制标识，如 `901F` |
| dataType | `auto`/`flow`/`int`/`float`/`bool` |
| scale / offset | 数值变换 |
| writable | 如阀门控制需开启 |

常用标识：`901F` 当前累计流量，`D120` 阀门状态，`901A` 电池电压。写操作支持开阀/关阀与写地址。
