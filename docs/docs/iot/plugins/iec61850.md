# IEC 61850 驱动插件

基于 MMS 的客户端驱动（MVP：Connect / Read / Write）。不含 Report、GOOSE、SV、SBO。

:::caution
底层库为 GPL-3.0，商用分发需自行评估合规。编译依赖 CGO。
:::

## 设备连接配置

| 参数 | Key | 默认 | 说明 |
|------|-----|------|------|
| IP | host | - | IED 地址 |
| 端口 | port | 102 | MMS 端口 |
| 连接超时 | connectTimeout | 10 | 秒 |
| 请求超时 | requestTimeout | 10 | 秒 |

## 物模型点位配置

| 字段 | 说明 | 示例 |
|------|------|------|
| address | 对象引用 | `simpleIOGenericIO/GGIO1.AnIn1.mag.f` |
| fc | 功能约束 | `MX` / `ST` / `SP` / `CO` |

```json
{
  "extConfig": {
    "protocol": "iec61850",
    "config": {
      "address": "simpleIOGenericIO/GGIO1.AnIn1.mag.f",
      "fc": "MX"
    }
  }
}
```
