# IEC 104 驱动插件

支持电力“四遥”。连接后会按公共地址自动总召；上行数据被动接收并缓存，读点时从缓存取值。

## 设备连接配置

| 参数 | Key | 说明 |
|------|-----|------|
| IP | host | 从站 IP |
| 端口 | port | 默认 `2404` |
| 公共地址 | commonAddress | 默认 ASDU/CA |
| 连接超时 | connectTimeout | 秒 |
| 周期总召 | interrogationInterval | 可选，秒；仅连接参数 |

相同 `IP:Port` 会复用 TCP 连接，靠公共地址区分逻辑装置。

## 物模型属性配置

| 字段 | 必填 | 说明 |
|------|------|------|
| address | 是 | 信息对象地址 IOA |
| asdu | 否 | 覆盖设备默认公共地址 |
| dataType | 否 | `bool`/`float32`/`int16` 等 |

缓存寻址键为 `ASDU:IOA`（如 `1:4001`）。

## 功能/指令下发配置

在功能定义中配置 TypeID（`function`）与地址：

| function | 含义 |
|----------|------|
| 45 / 58 | 单点遥控 |
| 46 / 59 | 双点遥控 |
| 47 / 60 | 步调节 |
| 48–50 / 61–63 | 遥调设定值 |
| 51 / 64 | 32 比特串 |
| 100 | 总召唤 |
| 101 | 电度总召 |
| 102 | 读命令 |
| 103 | 时钟同步 |
| 105 | 复位进程 |
| 107 | 带时标测试 |

控制类命令填写对应 IOA；管理类命令地址可忽略或置 0。参数类 TypeID 110–113 当前不支持下发。
